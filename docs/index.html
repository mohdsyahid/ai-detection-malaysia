How It Works

1. Behavioral Profiling Tests

  • Knowledge Cutoff Detection: Does it mention training data limits? (Claude/GPT often do)
  • Creativity Analysis: Response patterns to poetic/creative requests
  • Code Generation Test: Step-by-step explanations vs direct answers
  • Verbosity Assessment: Long elaborate responses (Claude) vs concise (Mistral)

2. Pattern Matching

Each response is analyzed against known model signatures:

  • Claude: hedging language, nuanced approach, detailed explanations
  • GPT-4: comprehensive structure, bullet points, confidence markers
  • Qwen: clean markdown, direct answers, efficient formatting
  • Llama/Mistral: neutral tone, brief responses, casual personality

3. Confidence Scoring

We calculate statistical confidence based on pattern matches and return ranked hypotheses. Scores above 60% = high confidence match.

🔍 Disclaimer
This tool uses probabilistic inference — results are hypotheses, not definitive proof. For production compliance, request official model cards from providers.
